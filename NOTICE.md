# Third-party and upstream materials

RetreatBench is an evaluation framework layered over independent upstream benchmarks. The Apache-2.0 license in this repository applies only to RetreatBench-authored code and documentation.

The following projects and their task assets retain their own licenses, terms, and citation requirements:

- Terminal-Bench 1.x
- Terminal-Bench 2.0
- Terminal-Bench-Science
- ResearchClawBench
- PaperWritingBench
- PaperWrite-Bench / PaperRecon
- Harbor

Adapters must record the exact upstream revision, per-task source hashes, and available license metadata. Do not vendor upstream papers, datasets, container layers, private ground truth, or evaluation keys unless redistribution is explicitly allowed. When rights are unclear, publish deterministic acquisition and conversion scripts instead.
