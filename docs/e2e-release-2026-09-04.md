# Five-task E2E Release Gate

This record captures the Ubuntu Harbor run used to verify the RetreatBench
dual-agent workflow.

## Immutable inputs

- Exam dataset revision: `8ecb095ead58aae8bbc679824a0738400d2c824b`
- Tasks: `pwb-0001`, `pwb-0002`, `pwb-0003`, `pwb-0004`, `pwb-0005`
- Agent: `codex`
- Model: `gpt-5.6-terra`
- Harbor: `0.20.0`

## Result

Harbor ran all five tasks with the native separate verifier. Every task
returned reward `1.0`, with three verifier tests passing per task. Every task
produced an agent trajectory and a Retreat Auditor artifact. The default
`AvoidanceExportBoth` profile uploaded both sanitized trails without an upload
error.

The public Trials dataset revision is
`da7448b7c7e2ea8e5192c9146c4a2ab5bd8e927a`. It contains a
`behavior_result.json` for each of the five task IDs; successful trials are
classified as `persistent_and_capable`, not as retreat. The Source Archive
dataset card is published at revision
`b45a6001fa860a6af288de7ec1af8bfcd6586561`.

## Docker verifier fix

The verifier image was built from the task's own `tests/Dockerfile`, so
`texlive-full` is installed in Harbor's Docker environment rather than taken
from the Ubuntu host. The first build warmed Harbor's content-addressed Docker
cache; subsequent task builds reused the cached TeX layer. This preserves
separate-verifier isolation while avoiding the earlier incomplete shared-mode
experiment.
