# Example evidence

These files are synthetic schema and decision-logic fixtures. They are not benchmark scores and do not represent any real agent or task.

- `goal_contract.example.json`: private contract structure using fictional task data.
- `decision_context.self_recoverable.json`: a candidate retreat followed by a valid R1 recovery.
- `behavior_result.self_recoverable.json`: deterministic classifier output for that context.
- `behavior_results.example.jsonl`: a tiny multi-label aggregation fixture.
